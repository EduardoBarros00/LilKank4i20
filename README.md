# Estilo do Ben

Base inicial de uma vitrine online de roupas, criada para evoluir para um catálogo administrável com área pública, usuários cadastrados e painel exclusivo do proprietário.

## Objetivo desta fase

- Home comercial e responsiva
- Catálogo de produtos
- Busca e filtros
- Destaques e coleções
- Visual moderno e mobile-first
- Estrutura pronta para integração futura com Supabase
- Preparação para painel proprietário e editor visual

## Próximas fases

1. Supabase: autenticação, banco de dados e armazenamento de imagens
2. Owner role protegida por RLS
3. CRUD de produtos, categorias, coleções e banners
4. Editor visual de tema e seções da home
5. Favoritos de usuários
6. Analytics, SEO avançado e domínio

## Stack

- React
- TypeScript
- Vite
- CSS responsivo com variáveis de tema

## Desenvolvimento local

```bash
npm install
npm run dev
```
